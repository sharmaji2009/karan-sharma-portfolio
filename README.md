# Karan Sharma — Premium Portfolio

A premium, responsive React + Vite personal portfolio designed as a personal brand website.

## Included
- Premium dark/light theme
- Full profile photo area
- About / Services / Skills
- Featured project showcase
- Resume download
- Direct email conversation form
- GitHub / LinkedIn / Instagram buttons
- Responsive mobile navigation
- Animated/glowing visual styling
- No backend required for contact

## Setup

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Add your personal files

Put:
- `profile.jpg` inside `public/`
- `resume.pdf` inside `public/`

See `public/README_ASSETS.txt` for details.

## Important
Update your real GitHub, LinkedIn and Instagram URLs in `src/main.jsx`.
